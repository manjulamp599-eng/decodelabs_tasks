# 🤖 Simple AI Chatbot

A simple **rule-based AI chatbot** built using Python. This project is designed for beginners to understand the basic concepts of chatbot development, Python programming, user input, conditions, and responses.

## 📌 Project Description

This project is a simple chatbot that interacts with users through the terminal.

The chatbot accepts questions or commands from the user and provides predefined responses based on the input.

It can answer basic questions related to:

* Artificial Intelligence
* Machine Learning
* Python
* Programming
* Computers
* Internet
* Study
* Exams
* College

## ⚙️ How It Works

The chatbot uses Python `if`, `elif`, and `else` statements.

When the user enters a question:

1. The chatbot receives the input.
2. The input is converted to lowercase.
3. The chatbot compares the input with predefined questions.
4. If a matching question is found, the chatbot displays the corresponding answer.
5. If no match is found, the chatbot displays an error message.
